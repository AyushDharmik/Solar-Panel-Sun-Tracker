# Solar Panel Sun Tracker

## Overview

The Solar Panel Sun Tracker is an Arduino-based system designed to improve solar energy harvesting by automatically orienting the solar panel toward the direction of maximum sunlight.

The system uses Light Dependent Resistors (LDRs) to detect light intensity and a servo motor to adjust the panel position accordingly.

## Features

* Automatic sunlight tracking
* Real-time panel adjustment
* Increased solar energy efficiency
* Low-cost and simple design
* Arduino-based implementation

## Components Used

* Arduino Uno
* LDR Sensors
* Servo Motor
* Solar Panel
* Resistors
* Breadboard
* Connecting Wires

## Working Principle

Two LDR sensors continuously measure sunlight intensity. The Arduino compares the sensor values and rotates the servo motor toward the brighter side. This ensures that the solar panel remains aligned with the strongest source of sunlight throughout the day.
